A LITTLE HELP

จัดการเส้นทางอย่างไร?

  1. เพิ่มแอปปลายทาง

    ไปที่ “แอปปลายทาง” ตั้งชื่อแอปและใส่ URL แบบ HTTPS ที่รับ Webhook

  2. เลือกแม่แบบ

    เลือกข้อความ กดปุ่ม หรือเพิ่มเพื่อน หรือสร้างกฎจากหน้า “เหตุการณ์ล่าสุด” แล้วเลือกแอปหรือ Reject กรณีปุ่ม LINE วางตัวอย่าง postback.data เพื่อช่วยเติมเงื่อนไขได้ ส่วน MFA ไป SSO มีเส้นทางให้แล้ว

  3. จัดลำดับและเลือกแอปสำรอง

    กฎบนสุดที่ตรงจะถูกเลือก กฎที่ปิดจะถูกข้าม ถ้าไม่ตรงกับกฎใดจะใช้ปลายทางเริ่มต้น ซึ่งเลือกแอปหรือ Reject ได้

  4. ทดลองก่อนบันทึก

    ใช้ “ทดลองเส้นทาง” ตรวจเงื่อนไข แล้วกด “บันทึกการเปลี่ยนแปลง” เพื่อให้มีผลกับงานถัดไป

การทดลองเส้นทางไม่ได้ตรวจว่าปลายทางออนไลน์หรือรับข้อมูลสำเร็จ
