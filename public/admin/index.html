A LITTLE HELP

จัดการเส้นทางอย่างไร?

  1. เพิ่มแอปปลายทาง

    ไปที่ “แอปปลายทาง” ตั้งชื่อแอปและใส่ URL แบบ HTTPS ที่รับ Webhook

  2. สร้างกฎตาม event

    กำหนดประเภท event เช่น message หรือ postback MFA ที่มี cusa_mfa มีเส้นทางป้องกันไป SSO ให้อัตโนมัติ กฎที่สร้างเองใช้กับ event อื่น

  3. จัดลำดับและเลือกแอปสำรอง

    กฎบนสุดที่ตรงจะถูกเลือก กฎที่ปิดจะถูกข้าม ถ้าไม่ตรงกับกฎใดจะใช้แอปสำรอง

  4. ทดลองก่อนบันทึก

    ใช้ “ทดลองเส้นทาง” ตรวจเงื่อนไข แล้วกด “บันทึกการเปลี่ยนแปลง” เพื่อให้มีผลกับงานถัดไป

การทดลองเส้นทางไม่ได้ตรวจว่าปลายทางออนไลน์หรือรับข้อมูลสำเร็จ
